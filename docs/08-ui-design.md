# 08 UI 設計

## 1. 技術

- Preact + `@preact/signals`。
- 全域 signal：`snapshot`（worker 推送）、`selectedSpeciesId`、`navHistory`、`groupMode`、`speed`。
- UI 偏好（`groupMode`、`sortMode`、`speed`、顯示已滅絕）存於資料庫 `setting` 表，並快取於 localStorage `ecosim.ui`。
- 圖鑑、歷史圖表、事件搜尋經 worker `query` 訊息取得（[10](10-database.md) §4）。
- 資料庫狀態 `memory`、`locked` 時，頂欄顯示對應警示。
- 支援淺色／深色主題，跟隨系統設定，可手動切換。

## 2. 版面

| 寬度 | 版面 |
|---|---|
| ≥ 1024 px | 頂欄；三欄（缸況｜物種列表｜物種詳情）；事件日誌；控制列 |
| 640–1023 px | 頂欄（含缸況摘要）；兩欄（物種列表｜物種詳情）；事件日誌與控制列可收合 |
| < 640 px | 頂欄；分頁（缸況／物種／詳情／日誌）；底部固定控制列 |

```
┌─ 頂欄：缸名｜第 12 日 08:00｜⏸ 1× 4× 16×｜生態分數 342｜圖鑑 ─────────┐
├─ 缸況 ─────────┬─ 物種列表 ─────────────────┬─ 物種詳情 ─────────────┤
│                │                             │                        │
├────────────────┴─────────────────────────────┴────────────────────────┤
│ 事件日誌                                                               │
├─ 控制列：餵食｜換水｜光照｜溫度｜曝氣｜投放｜撈除｜用藥｜加入造景 ─────┤
```

## 3. 頂欄

缸名、遊戲時間（第 N 日 HH:00、日夜圖示）、速度切換、生態分數、圖鑑入口、設定。

## 4. 缸況面板

| 群組 | 項目 |
|---|---|
| 環境 | 水溫、鹽度、pH、光照（開／關、強度）、水流、曝氣 |
| 水質 | 溶氧、游離氨、亞硝酸、硝酸鹽、磷酸鹽、矽酸鹽、鈣（海水） |
| 有機物 | 碎屑、殘餌 |
| 陸域 | 空氣溫度、濕度、土壤濕度、落葉、曬點溫度、UVB、加蓋 |

無水域時隱藏「水質」；無陸域時隱藏「陸域」。

- 每項顯示數值、單位與 24 小時趨勢（↑ ↓ →）。
- 狀態色：正常／注意／危險；閾值與 [06](06-gameplay.md) §4 事件條件一致。

## 5. 物種列表

### 5.1 分組

| 模式 | 分組依據 |
|---|---|
| 營養層（預設） | 功能群所屬層：L1 分解者、L1 生產者、L2、L3、L3-P、L4、L5、L6 |
| 生物類別 | [02](02-ecosystem-catalog.md) §4 |
| 區域 | 水域、陸域、兩棲 |
| 棲位 | 物種 `habitat` 第一項 |

- 群組標題：名稱、物種數、總個體數或總生物量；可收合。
- 空群組不顯示。

### 5.2 列欄位

| 欄位 | cohort 型 | biomass 型 |
|---|---|---|
| 名稱 | 中文俗名；滑鼠移入顯示學名 | 同左 |
| 數量 | 個體數，`1,240（成 820／幼 420）` | 豐度等級 + 生物量 mg/L |
| 走勢 | 近 7 日每日平均，8 階方塊字元 `▁▂▃▄▅▆▇█` | 同左 |
| 趨勢 | 24 小時變化 > +10% ↑、< −10% ↓、其餘 → | 同左 |
| 標記 | 🆕 湧現 ≤ 3 遊戲日；⚠ 承受壓力；🕰 老年個體 > 50%；☠ 已滅絕 | 🆕、⚠、☠；`clonal_aging` 達 `clonalMax` 的 80% 時 🕰 |

**豐度等級**（`B / K`）：< 1% 稀少、1–10% 少量、10–40% 普通、40–80% 豐富、> 80% 優勢。

### 5.3 操作

- 排序：數量、趨勢、名稱、出現時間。
- 搜尋：俗名、學名、功能群名稱。
- 顯示已滅絕：開啟時保留滅絕物種（灰色）；關閉時滅絕後 3 遊戲日移除。
- 選取物種時，列表標示關係：上游食物 ▲、下游天敵 ▼、競爭者 ↔。

## 6. 物種詳情

### 6.1 區塊順序

1. **標頭**：俗名、學名、功能群、生物類別、營養層等級（TL，小數一位）、稀有度、來源徽章、首次出現時間、親物種（可點擊）。
2. **族群**：目前數量、近 30 遊戲日走勢、壓力狀態與原因；年齡結構（幼體／成體／老年個數與文字長條）、年齡中位數、典型壽命／最長壽命；biomass 型顯示世代時間，`clonal_aging` 另顯示克隆代數／上限。
3. **關係圖**（§6.2）。
4. **關係清單**（§6.3）。
5. **食物鏈路徑**（§6.4）。
6. **基因型與特徵**：各基因座等位基因（例：體型 中大｜溫度帶 熱帶｜花紋 虎斑…）；推導特徵：體型、食性、耐受範圍、繁殖、壽命、活動、防禦、特殊標記；依據為 estimated 的數值附「（估）」標示，滑鼠移入顯示來源或「尚無來源」。
7. **操作**：撈除（符合條件時）。

### 6.2 關係圖

- SVG，以選取物種為中心。
- 上排：食物，依占比取前 5，其餘合併為「+N」。
- 中央：選取物種。
- 下排：天敵，依占比取前 5，其餘合併為「+N」。
- 邊寬與占比成正比；潛在關係以虛線呈現。
- 節點顏色依營養層；非物種資源（碎屑、殘餌、DOC）以方框呈現。
- 點擊物種節點即切換選取。
- 每個節點為 `button`，`aria-label` = 名稱 + 關係 + 占比。

### 6.3 關係清單

| 區塊 | 定義 | 排序 |
|---|---|---|
| ▲ 食物（上游） | 近 7 遊戲日，選取物種攝食來源的通量占比 | 占比由大到小 |
| ▼ 天敵（下游） | 近 7 遊戲日，選取物種被捕食的通量占比 | 占比由大到小 |
| 潛在食物／天敵 | 同缸存在、`a_ij > 0`、占比 < 1% | 名稱 |
| ↔ 競爭者 | 食性重疊（Pianka 指數）≥ 0.3 | 重疊度由大到小 |
| ⇄ 共生 | 共生關係（珊瑚 ↔ 蟲黃藻） | — |
| ⚗ 化學影響 | 近 7 遊戲日化學通量前 3 名（產 O₂、耗 O₂、排氨、吸收硝酸鹽等） | 絕對量由大到小 |

**Pianka 重疊指數**
`O_ik = Σ_j p_ij p_kj / √(Σ_j p_ij² × Σ_j p_kj²)`；`p_ij` 為物種 i 近 7 遊戲日攝食中 j 的占比。

### 6.4 食物鏈路徑

- 向下：從選取物種起，反覆取占比最大的食物，直到生產者或非物種資源。
- 向上：從選取物種起，反覆取占比最大的天敵，直到沒有天敵。
- 呈現：`矽藻 → 赤斑劍水蚤 → 銀鱗小魚 → 巨口魚`，選取物種以粗體標示。
- 遇到已走過的節點即停止（同類相食、循環）。

### 6.5 導覽

- 麵包屑記錄最近 10 次選取，可點擊返回。
- 鍵盤：列表中 ↑ ↓ 移動、Enter 選取、Backspace 返回上一個選取、Esc 取消選取。

## 7. 事件日誌

- 每筆事件：遊戲時間、等級圖示、內容；內容中的物種名稱可點擊選取。
- 篩選：一般／注意／重大。
- 保留最近 500 筆。

## 8. 其他畫面

| 畫面 | 內容 |
|---|---|
| 建缸精靈 | 步驟：缸型與尺寸（陸域比例、水深）→ 水體 → 底材與造景 → 光照、過濾、溫度 → 陸域設備（噴霧、加熱燈、UVB、加蓋）→ 水源與開放系統 → 種子與確認；無水域或無陸域時略過對應步驟；每步顯示該選項影響的說明與可容納的最大體型 |

## 9. 快照資料契約

```ts
interface Snapshot {
  tick: number;
  environment: EnvironmentView;
  chemistry: ChemistryView;          // 含 24 小時趨勢
  score: number;
  populations: PopulationView[];
  foodWeb: FoodWebEdge[];
  chemFlux: Record<SpeciesId, Partial<Record<ChemFluxKind, number>>>;  // 近 7 遊戲日累計
}

interface PopulationView {
  speciesId: SpeciesId;
  kind: 'biomass' | 'cohort';
  adults?: number;
  juveniles?: number;
  biomass: number;                   // mg/L
  abundance: number;                 // B / K
  history7d: number[];               // 每日平均，長度 7
  history30d: number[];              // 每日平均，長度 30；僅選取物種附帶
  trend24h: number;                  // 變化比例
  stress: StressKind[];
  trophicLevel: number;
  extinctAtTick?: number;
  ageStructure?: { juvenile: number; adult: number; senescent: number };  // cohort 型
  medianAgeDays?: number;            // cohort 型
  clonalGenerations?: number;        // clonal_aging
}

type NodeId = SpeciesId | 'detritus' | 'food' | 'doc';

interface FoodWebEdge {
  from: NodeId;                      // 被吃者
  to: SpeciesId;                     // 攝食者
  flux7d: number;                    // 近 7 遊戲日攝食量（mg）
  potential: boolean;                // a_ij > 0 且 flux7d 占比 < 1%
}
```

## 10. 效能

- 快照推送 ≤ 4 Hz；未變動的列不重新渲染。
- `history30d` 只在選取物種時附帶。
