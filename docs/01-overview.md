# 01 專案概覽

## 1. 定位

文字型放置（idle）水族箱生態模擬器。玩家設定水族箱環境（可含陸域，從純水族缸到純陸缸），系統依環境條件隨機湧現生物，形成從微生物到頂端掠食者的完整生態系，並自行演化。玩家可做有限度的干預。

## 2. 核心循環

1. 建缸：選擇水體、容量、底材、造景、光照、過濾、溫度、水源與種子。
2. 湧現：生物依環境適合度與來源途徑隨機出現，每個物種由功能群模板加上隨機特徵生成。
3. 演化：族群依攝食、代謝、繁殖、衰老、死亡動態變化，可能滅絕，或在繁殖時突變出新物種。
4. 干預：餵食、換水、調整環境、投放、撈除、用藥。
5. 累積：圖鑑收錄、生態分數。

## 3. 範圍決策

| 項目 | 決策 |
|---|---|
| 平台 | Web，瀏覽器單頁應用 |
| 技術棧 | TypeScript（strict）、Vite、Vitest、Preact + Signals |
| 資料庫 | SQLite WASM（OPFS）：參考資料、圖鑑、缸存檔、族群歷史、事件、通量紀錄 |
| 水體 | 淡水、半鹹水、海水；鹽度為連續環境軸 0–35 ppt |
| 陸域 | 陸域比例 0–100%：水族缸、水陸缸、雨林缸、純陸缸 |
| 缸體 | 自訂長寬高，總容積 ≤ 100,000 L |
| 體型 | 依各功能群最小飼養空間限制；不另設全域上限 |
| 物種 | 111 個真實功能群 × 離散基因型（含突變基因座）；理論物種數 ≈ 4.24 × 10¹¹ |
| 隨機性 | 種子預設隨機；湧現、基因型、突變、搭便車皆為隨機事件 |
| 壽命 | 所有個體、細胞、模組、群體皆有年齡上限 |
| 遊戲性 | 沙盒，無失敗條件；圖鑑收集；生態分數 |
| 呈現 | 文字為主的介面；物種詳情附小型關係圖 |
| 物種列表 | 預設依營養層分組，可切換生物類別、棲位 |

## 4. 非目標（v1）

- 恆溫動物（鳥類、哺乳類）
- 圖形或動畫渲染
- 後端伺服器、帳號、多人
- 多缸同時運行（圖鑑跨缸共用，同時只運行一缸）

## 6. 名詞

| 名詞 | 定義 |
|---|---|
| 功能群（Archetype） | 真實生物類群的模板，定義特徵範圍與來源途徑 |
| 物種（Species） | 功能群 + 基因型；ID 即基因型編碼，具唯一學名 |
| 基因座（Locus） | 物種的一個離散特徵維度，例如體型、溫度帶、花紋 |
| 族群（Population） | 某物種在缸內的存活實例 |
| tick | 模擬最小時間步 = 1 遊戲小時 |
| 來源途徑（Vector） | 生物進入水族箱的方式 |
| 湧現（Emergence） | 物種經來源途徑進入並成功建立族群 |
