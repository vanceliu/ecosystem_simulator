# 05 物種生成

## 1. 物種模型

- 物種 = 功能群 + 基因型。
- 基因型：功能群的一組離散基因座（locus），每個基因座取一個等位基因（allele）。
- 表現型（模擬用特徵）由「功能群 + 基因型」決定性推導；同一基因型在任何缸、任何時間皆為同一物種。
- 基因型編碼：各基因座等位基因索引組成的混合進位整數，以 base-36 表示，前綴功能群 ID，例如 `copepod:3f9k2a`。此字串為物種 ID、物種簽章與圖鑑鍵。

```ts
interface Species {
  id: GenotypeCode;           // `${archetypeId}:${base36}`
  archetypeId: string;
  alleles: number[];          // 依功能群基因座順序
  parentId?: GenotypeCode;    // 突變來源
}
// 表現型、學名、俗名由 id 決定性推導，不儲存。
```

## 2. 基因座

### 2.1 共通基因座（所有功能群）

| 基因座 | 等位基因數 | 等位基因 | 表現型 |
|---|---|---|---|
| `size` 體型 | 7 | 微、小、中小、中、中大、大、巨 | `adultMass`：功能群質量範圍（對數）七等分取區間中點；超出缸可容納體長時權重為 0（[09](09-life-history.md) §7） |
| `thermal` 溫度帶 | 5 | 冷水、溫帶、廣溫、暖水、熱帶 | 溫度 opt 14／20／22／26／29 °C（限制在功能群範圍內側 10%）；物種耐受半寬 = 功能群範圍半寬 × 0.6，廣溫 × 1.6；截於功能群範圍 |
| `salinity` 鹽度帶（W、A） | 4 | 低端狹鹽、低端廣鹽、高端廣鹽、高端狹鹽 | 自功能群鹽度範圍的低端或高端起算，寬度 = 範圍 × 0.4（狹）或 × 0.75（廣） |
| `humidity` 濕度帶（T，取代 `salinity`） | 4 | 乾燥、中濕、潮濕、飽和 | `humidityMin` = 功能群下限 −20／−10／0／+10%，限制於 10–95% |
| `ph` 酸鹼帶 | 3 | 偏酸、中性、偏鹼 | pH opt 6.5／7.2／8.0，截於功能群範圍 |
| `hardiness` 耐受 | 3 | 嬌弱、一般、強健 | `nh3Max`、`no2Max` × 0.6／1.0／1.5；`o2Min` × 1.3／1.0／0.8；成長率 × 1.1／1.0／0.9 |
| `growth` 成長策略 | 3 | 快速、均衡、節能 | `muMax` 或 `r0` × 1.25／1.0／0.8；同化效率 × 0.9／1.0／1.1 |
| `lifespan` 壽命型 | 3 | 短命、一般、長壽 | [09](09-life-history.md) 壽命範圍三分：短～典型下限、典型、典型上限～最長 |
| `mutation` 突變 | 11 | 無、白化、黑化、巨大化、侏儒化、發光、長壽、多產、廣溫、廣鹽、抗藥 | 見 §2.7 |
| `pigment` 色素／體色 | cohort 12；biomass 6 | 赤、橙、金、黃、綠、碧、藍、紫、褐、墨、雪、透明（biomass：綠、褐、紅、藍綠、金、無色） | 外觀；光合生物：紅、褐 `kI` × 0.7、`iOpt` × 0.8（低光適應），金、無色 `iOpt` × 1.2 |

### 2.3 biomass 型附加基因座

| 基因座 | 等位基因數 | 等位基因 | 表現型 |
|---|---|---|---|
| `morphology` 形態 | 8 | 功能群定義（例：球狀、桿狀、絲狀、鏈狀、群體、扁平、星狀、螺旋） | 外觀；`K` × 0.8–1.2（功能群定義） |
| `metabolism` 代謝型 | 4 | 高親和、均衡、高速、特化 | 高親和：半飽和常數 × 0.5、`muMax` × 0.8；高速：半飽和常數 × 1.5、`muMax` × 1.2；特化：功能群定義 |

**特化代謝效果**（`metabolism` = 特化時套用；數值與來源見 `src/content/archetypes` 的 `specialised`）

| 功能群 | 特化 | 效果 |
|---|---|---|
| `aob` | 耐低氧 | O₂ 半飽和 × 0.5 |
| `nob` | 完全硝化 | 另以 tan 為基質直接氧化為 no3（半飽和 0.012 mg N/L，速率 0.3 × `muMax`） |
| `heterotroph` | 寡營養 | 基質半飽和 × 0.1；惰性有機物每日 0.002 轉為可分解基質 |
| `denitrifier` | 好氧脫氮 | 有氧時保留 50% 脫氮 |
| `water_mold` | 寄生 | 以卵為食，最大攝食每日 0.5 × 自身生物量 |
| `biofilm` | 光合型 | 光照下另以 0.5 × `muMax` 光合成長 |
| `diatom` | 低矽 | 矽沉積 × 0.4 |
| `green_algae` | 碳酸氫根利用 | CO₂ 半飽和 × 0.3 |
| `cyanobacteria` | 產毒 | 被捕食率 × 0.25 |
| `phytoplankton` | 混合營養 | 黑暗中以 0.5 × `muMax` 利用溶解有機物 |
| `aquatic_plant` | 挺水 | CO₂ 不受限、不與水交換 O₂／CO₂；成長 × 2 |
| `macroalgae` | 鈣化 | 每 mg COD 成長沉積 Ca 1.13 mg |
| `zooxanthellae` | 耐熱 | 宿主珊瑚白化門檻 +1.25 °C；光合產物 × 0.5 |
| `ciliate` | 共生藻 | 光照下另以 0.15 × `muMax` 光合成長 |
| `moss_liverwort` | 耐旱 | 乾燥死亡率 × 0.1 |
| `terrestrial_plant` | 耐陰 | 光半飽和與最適光 × 0.4 |
| `bromeliad_epiphyte` | CAM | `humidityMin` −20%；成長 × 0.63 |
| `saprotrophic_fungus` | 白腐 | 落葉每日 0.01 直接分解；成長 × 0.5 |
| `soil_bacteria` | 芽孢 | 乾燥死亡率 × 0.02 |

- 光合型與共生藻的光反應採 `phytoplankton` 功能群光參數。
- 寡營養與白腐的分解在菌株生物量達所屬棲位容量 1% 時達全速，低於時等比例降低。
- 每個珊瑚物種攜帶固定的蟲黃藻基因型（由珊瑚物種 ID 決定），其特化效果作用於該珊瑚。

### 2.4 物種空間

| 族群型態 | 功能群數 | 每功能群組合數 | 小計 |
|---|---|---|---|
| biomass | 19 | 7·5·4·3·3·3·3·11·6·8·4 = 23,950,080 | 455,051,520 |
| cohort | 92 | 7·5·4·3·3·3·3·11·12·8·4·3·4·4·2 = 4,598,415,360 | 423,054,213,120 |
| **合計** | 111 | — | **423,509,264,640（≈ 4.24 × 10¹¹）** |

排除純外觀基因座（`pigment`、`pattern`）後，生態行為相異的組合為 4,482,656,640（≈ 4.48 × 10⁹）。單一缸可出現的數量受飼養空間限制（`size` 等位基因權重為 0 者不計）。

### 2.5 連續值微擾

每個連續表現型值 × `(1 + 0.05u)`，`u ∈ [−1, 1]` 由 `hash(物種 ID, 特徵名)` 決定。

### 2.6 權衡約束（推導後套用）

- `eggMass` 基準 = `adultMass × 0.01`
- `clutchSize × eggMass ≤ 0.3 × adultMass`
- 具 `shell` 防禦 → 成長率 × 0.85
- 具 `toxin` 防禦 → 代謝率 × 1.1

### 2.7 突變等位基因效果

| 突變 | 效果 |
|---|---|
| 白化 | 體色固定為白；被捕食攻擊率 × 1.2；光合生物 `muMax` × 0.7 |
| 黑化 | 體色固定為墨；被捕食攻擊率 × 0.9；溫度 opt +1 °C |
| 巨大化 | `adultMass` × 2.5（可超出功能群範圍）；壽命 × 1.2；`clutchSize` × 0.7 |
| 侏儒化 | `adultMass` × 0.4；壽命 × 0.8；`maturityDays` × 0.7 |
| 發光 | 夜間攻擊率 × 1.15；夜間被捕食攻擊率 × 1.3 |
| 長壽 | `lifespanTyp`、`lifespanMax` × 1.5，不超過遊戲上限；成長率 × 0.85 |
| 多產 | `clutchSize` × 1.8；幼體存活 × 0.7 |
| 廣溫 | 溫度耐受寬度 × 1.8 |
| 廣鹽 | 鹽度耐受範圍向兩側各擴 50%，截於 0–35 ppt |
| 抗藥 | 加上 `medication_resistant` |

## 3. 基因型抽樣

**基準權重**

| 基因座類型 | 權重 |
|---|---|
| 7 等位（`size`） | 1、4、10、14、10、4、1 |
| 5 等位（`thermal`） | 1、4、6、4、1 |
| 3 等位有序（`ph`、`hardiness`、`growth`、`lifespan`） | 1、3、1 |
| `mutation` | 無 10,000；每種突變 1 |
| 其他 | 均等；功能群可覆寫 |

**湧現抽樣**：環境相關基因座（`thermal`、`salinity`、`ph`、`hardiness`）權重 × `max(0.05, 該等位基因表現型在目前缸況的 f_env)`，再正規化抽樣；其餘基因座依基準權重。

**玩家投放**：與湧現相同的環境加權抽樣，重抽至該物種在目前缸況 `f_env > 0`（最多 8 次）；從圖鑑投放時直接使用該物種。

## 4. 命名

### 4.1 學名（唯一）

學名與基因型一一對應（雙射），無需碰撞處理。

- **屬名** = 拉丁字幹 + 連接音節 + 體型音節 + 字尾
  - 拉丁字幹：每功能群 1 個（取自代表屬名，例 `Cyclo`），全功能群唯一
  - 連接音節：`ra`、`li`、`mo`、`ne`，依 `diet`（cohort）或 `metabolism`（biomass）選取
  - 體型音節：`pi`、`mi`、`ta`、`ro`、`ma`、`gra`、`gi`，依 `size` 選取
  - 字尾：cohort 依 `habitat`（`ella`、`opsis`）；biomass 依 `morphology`（`ella`、`ina`、`ula`、`ia`、`ium`、`opsis`、`ites`、`ora`）
  - 每功能群屬數：cohort 56、biomass 224；跨功能群屬名不重複
- **種小名** = 其餘基因座（不含 `mutation`）組成的混合進位索引，轉為 base-64 音節（16 子音 × 4 母音），定長：cohort 4 音節、biomass 3 音節；接上與屬名詞性一致的拉丁字尾（`-ium` 中性 `um`、`-ites` 陽性 `us`、其餘陰性 `a`）。子音：b c d f g l m n p r s t v qu th ph；母音：a e i o。
- **變種名**：`mutation` ≠ 無時附加 `var.` + 變種名：`albina`、`melanica`、`gigantea`、`nana`、`lucifera`、`longaeva`、`fecunda`、`eurytherma`、`euryhalina`、`resistens`。
- 例：`Cycloramaella betolia`、`Cycloramaella betolia var. albina`

### 4.2 中文俗名（描述性）

`修飾詞（1–2 個）+ 功能群通稱`。修飾詞依顯著度取前兩名：

| 優先 | 來源 | 修飾詞例 |
|---|---|---|
| 0 | `mutation` ≠ 無 | 白化、黑化、巨型、侏儒、螢光、長壽、多產、廣溫、廣鹽、抗藥 |
| 1 | `size` 微、巨 | 微、巨 |
| 2 | `pigment` | 赤、金、碧、墨、雪、透明 |
| 3 | `pattern` 非素面 | 斑、紋、環、網、虎、擬態 |
| 4 | `activity` 夜行 | 夜 |
| 5 | `defense` | 棘、甲、毒 |
| 6 | `thermal` 冷水、熱帶 | 寒、熱帶 |
| 7 | `salinity` 廣鹽 | 廣鹽 |

例：`赤斑劍水蚤`、`夜甲蜑螺`、`白化劍水蚤`。白化、黑化時不取 `pigment` 修飾詞。俗名可重複；同缸內重複時依出現順序加「甲型、乙型、丙型…」。

## 5. 突變

**發生**

| 族群型態 | 時機 | 機率 |
|---|---|---|
| cohort | 每產出一個新世代群 | `p = 1 − (1 − μ)^n`，`n` = 新生個體數，`μ = 2 × 10⁻⁵` |
| biomass | 每遊戲日 | `p = μ_b × log10(B / cellMass + 1)`，`μ_b = 5 × 10⁻⁴` |

**內容**

- 85%：一般基因座變動。90% 改變 1 個基因座、10% 改變 2 個；有序基因座 ±1（截於範圍），無序基因座隨機換為其他等位基因。
- 15%：`mutation` 基因座變動。原為「無」→ 隨機一種突變；原為突變 → 50% 回到「無」、50% 換為其他突變。

**突變族群**

- cohort：從新世代群分出 `min(5, count)` 個體成立新族群。
- biomass：從親族群分出 1% 生物量成立新族群。
- 新族群通過建立判定（[04](04-simulation-model.md) §7）後列入圖鑑；未通過前依模擬自然存續或滅絕。
- `parentId` = 親物種 ID；`origin = 'mutation'`。
- 子基因型已存在於同缸時，併入該族群。

## 6. 稀有度

- `P_base`：基因型在基準權重下的機率。
- 稀有度分數 = `−log10(P_base / P_max)`，`P_max` 為該功能群最常見基因型機率。

| 稀有度 | 分數 |
|---|---|
| 常見 | < 2 |
| 少見 | 2–4 |
| 稀有 | 4–6 |
| 傳說 | ≥ 6 |

來源徽章（與稀有度並列）：背景、水源、搭便車、開放系統、投放、突變。
