|---|---|---|

## 2. 玩家干預

| 指令 | 參數 | 效果 |
|---|---|---|
| 餵食 | 量（少、中、多）；種類（薄片、沉底錠、冷凍蟲、浮游植物液、冷凍餌魚、冷凍餌鼠） | 增加 `food`；浮游植物液增加 `phytoplankton` |
| 投放活餌 | 蟋蟀、果蠅、跳蟲培養、麵包蟲 | 加入對應功能群族群；未被吃完者可能以 `feeder_escape` 建立族群 |
| 噴霧 | — | 濕度 +10、土壤濕度 +0.05 |
| 加入落葉 | — | `litter` 增加；擲 `leaf_litter` 搭便車骰 |
| 調整陸域設備 | 噴霧頻率、加熱燈、UVB、加蓋 | 立即生效 |
| 換水 | 10–90% | 化學池依比例回到水源值；依水源擲接種骰 |
| 調整光照 | 強度、光週期 | 立即生效 |
| 調整溫度 | 設定值 | 依加熱器速率趨近 |
| 曝氣 | 開／關 | 立即生效 |
| 投放 | 功能群（從該群隨機生成新物種）或圖鑑物種 | 投放 5 個成體，不超過最小飼養空間的每缸數量；缸不符飼養空間時拒絕並顯示原因 |
| 撈除 | 族群、比例 10–100% | 僅限 cohort 型且 `adultMass ≥ 1 mg` |
| 加入水草／活石／沉木 | — | 增加 `surfaceArea` 與庇護所；擲對應搭便車骰 |
| 用藥：殺無脊椎藥 | — | 無脊椎死亡率 +0.1/tick，持續 3 遊戲日；具 `medication_resistant` 者免疫 |
| 用藥：殺藻劑 | — | 藻類、藍綠菌死亡率 +0.1/tick，持續 3 遊戲日；死亡生物量轉入碎屑 |
| 用藥：抗生素 | — | 藍綠菌死亡率 +0.1/tick；硝化菌死亡率 +0.03/tick，持續 3 遊戲日 |
| 重置 | — | 以新設定開新缸；圖鑑保留 |

## 3. 放置機制

- 分頁開啟時依所選速度持續模擬。
- 重新開啟時，以 `lastSavedAt` 計算離線時間，按 1× 速度換算 tick 數並追算，上限 30 遊戲日（720 tick）。
- 追算在 worker 內進行並回報進度（已完成 tick ÷ 總 tick），UI 顯示進度條；族群數多時追算可能需約一分鐘。
- 追算期間不套用玩家指令。
- 追算完成後顯示摘要：新物種、滅絕物種、族群變化最大的前 5 名、重大事件。

## 4. 事件

| 事件 | 觸發條件 |
|---|---|
| 新物種湧現 | 族群通過建立判定 |
| 物種滅絕 | 見 [04](04-simulation-model.md) §8 |
| 突變種出現 | 突變族群通過建立判定（[05](05-species-generation.md) §5） |
| 開缸循環開始 | 狀態「無負荷」時 `tan` 或 `no2` 首次 > 0.25 mg/L |
| 開缸循環完成 | 累積硝化 ≥ 0.5 mg N/L，且連續 7 遊戲日 `tan < 0.25`、`no2 < 0.25` |
| 藻華 | 任一藻類生物量單日成長 > 50% 且 > 0.5K |
| 白濁 | `heterotroph` 水層生物量 > 0.5K |
| 缺氧 | `o2 < 3 mg/L` |
| 氨／亞硝酸飆升 | `NH3_free > 0.05` 或 `no2 > 1` |
| 族群爆發 | cohort 族群 3 遊戲日內數量 ×3 |
| 珊瑚白化 | 蟲黃藻密度 `Z < 0.5` |
| 羽化離缸 | `odonate_nymph` 成體移出 |
| 營養層突破 | 首次出現 TL ≥ 3、≥ 4 的族群 |
| 傳說物種 | 稀有度「傳說」的物種通過建立判定 |
| 克隆崩潰 | `clonal_aging` 族群達 `clonalMax` |
| 變態上岸 | 兩棲類幼體首次變態為成體 |
| 外來入侵 | `outside` 途徑族群通過建立判定 |
| 結冰／解凍 | 戶外 `iceCover` 改變 |
| 乾涸 | 戶外水量降至 10% 以下 |
| 季節變化 | 進入雨季、乾季，或日照長度跨越 12 小時（春分、秋分） |
| 生態系飽和 | 族群數達效能保險上限（[04](04-simulation-model.md) §9.2） |
| 活餌建立族群 | `feeder_escape` 途徑族群通過建立判定 |
| 乾燥警示 | `humidity` 低於任一現存陸域族群的 `humidityMin` |
| 缺 UVB 警示 | 缸內有爬蟲類且 `uvb = false` 達 30 遊戲日 |

事件分級為一般、注意、重大；重大事件觸發自動存檔。

## 5. 圖鑑與分數

### 5.1 圖鑑

條目欄位：學名、俗名、功能群、營養層、基因型摘要、特徵摘要、壽命範圍、來源徽章、稀有度、首次發現時間與缸、歷史最大族群量、親物種。

- 稀有度與來源徽章見 [05](05-species-generation.md) §6。
- 圖鑑進度：已發現數／理論總數，分全體與各功能群顯示（理論總數見 [05](05-species-generation.md) §2.4）。

### 5.2 生態分數

- 多樣性：`H' = −Σ p_i ln p_i`，`p_i` 為各族群生物量占比（不含 `heterotroph`、`aob`、`nob`、`denitrifier`）
- 營養層數：`L` = 存在族群的最高 TL 取整
- 穩定係數：`S = clamp(1 − CV(近 30 遊戲日每日總生物量), 0, 1)`
- 生態分數 = `round(100 × H' × (1 + 0.25 × L) × (0.5 + 0.5 × S))`

## 6. 平衡驗收指標（M6）

以每種預設缸型 × 20 個種子 × 365 遊戲日批次模擬：

| 指標 | 目標 |
|---|---|
| 開缸循環完成時間（自來水、乾淨材料、每日餵食） | 中位數落在 28–56 遊戲日 |
| 不餵食、水與材料皆乾淨 | 365 日內維持「無負荷」 |
| 不餵食、野外水與野外材料 | 120 日內「已完成」 |
| 無干預下 365 日仍存活的功能群數 | 中位數 ≥ 8 |
| 出現 TL ≥ 3 族群的種子比例（含玩家投放情境） | ≥ 80% |
| 單一物種占非微生物生物量 > 90% 的種子比例 | ≤ 10% |
| 餵食「多」連續 30 日 → 碎屑食者爆發 | 100% 種子 |
| 強光 + 高 PO₄ → 藻華 | 100% 種子 |
| 雨林缸（陸 80%）無干預 365 日仍存活的陸域功能群數 | 中位數 ≥ 5 |
| 戶外溫帶大陸性池塘跨冬 | 冰封期間溶氧下降；至少一個魚類以外的功能群存活到春季 |
| 自然來源湧現的功能群 | 100% 屬於所選生物地理區或世界性分布 |
| 自然穩定後的族群數 | 所有缸型與尺寸皆未觸發效能保險（2,000） |
| 純陸缸、水族缸皆可完成 365 日模擬且無數值錯誤 | 100% 種子 |
| 各功能群平衡期密度中位數 | 落在 [09](09-life-history.md) 一般密度 ÷ 3 至最大密度之間 |
| 無外因死亡下的平均壽命 | 落在 [09](09-life-history.md) 典型壽命 ±20% |
| 365 日內圖鑑新增物種數（無干預） | 中位數 ≥ 30 |
