# 使用者手冊

> 本手冊依設計規格撰寫，隨功能實作同步更新。

## 1. 這是什麼遊戲

你是一個水族箱的主人，但不是造物者。你決定缸子的環境：水、沙、陸地、光、溫度、濕度，然後生物會自己出現。細菌先來，接著是藻類、苔蘚、微小的蟲子，最後可能是蛙、蜥蜴、蛇或大型掠食魚。每一缸的物種都是隨機生成、獨一無二的。

缸子可以是純水族缸、有陸地的水陸缸、雨林缸，也可以是完全沒有水的純陸缸；最大可以到 100,000 L 的公共水族館等級。

你可以照顧它，也可以只是看著它。

## 2. 快速開始

1. 開啟遊戲，選擇「新水族箱」。
2. 新手建議設定：淡水、30 L、細砂 5 cm、水草 + 沉木、光照中 8 小時、海綿過濾、曝氣開、加熱器 25 °C、水源「熟成缸水」。
3. 按「開缸」。
4. 前 4–8 遊戲週是**開缸循環期**：氨和亞硝酸會先上升再下降。這段期間少餵食。
5. 看到「開缸循環完成」事件後，生態系進入穩定成長期。

### 3.2 看懂上下游關係

點擊任一物種，詳情面板會顯示：

- **關係圖**：上排是牠吃的（食物），下排是吃牠的（天敵）；線越粗代表比例越高，虛線是「能吃但最近沒吃到」。點擊圖中物種可直接切換過去。
- **▲ 食物**、**▼ 天敵**：近 7 日的實際比例。
- **↔ 競爭者**：和牠搶同樣食物的物種。
- **食物鏈路徑**：從最底層到最頂端的主要能量路徑，例如 `矽藻 → 劍水蚤 → 小魚 → 肉食魚`。
- 選取物種後，列表中的食物會標 ▲、天敵標 ▼、競爭者標 ↔。

鍵盤：↑ ↓ 移動，Enter 選取，Backspace 回上一個物種，Esc 取消選取。

## 4. 地點與季節

建缸第一步是選擇「地點」：半球、緯度帶（熱帶到寒帶）、海拔帶（低地到高山）、乾濕型（全年濕潤、乾濕季、地中海型、半乾旱、乾旱），再選棲地類型（溪流、雨林地面、紅樹林、珊瑚礁、沙漠……）和生物地理區（例如新熱帶區、東洋區）。

- 遊戲會依地點與棲地自動填入推薦設定：陸域比例、水深、水溫、pH、濕度、光照等，你可以任意修改。
- 不合理的組合會停用並說明原因，例如寒帶沒有珊瑚礁。
- 生物地理區決定池塘水、開放系統、缸外等自然來源會帶來哪些生物：選新熱帶區可能遇到箭毒蛙，選東洋區可能遇到火鱔。你自己投放則不受限制。
- **室內**：地點只影響推薦設定；可開啟「季節光照」，讓燈光的日照長度跟著季節變化。
- **戶外**：氣溫、陽光、濕度、降雨都跟著當地季節走。寒冷地區的冬天水面會結冰，冰下溶氧會下降；乾旱地區的水會蒸發，水位下降。
- 海拔越高，氣溫越低、水中溶氧越少。

## 4.1 建缸選項

| 選項 | 說明 |
|---|---|
| 水體 | 淡水、半鹹水、海水，或自訂鹽度。決定哪些生物能生存 |
| 缸型 | 水族缸（無陸地）、水陸缸、半水半陸、雨林缸、純陸缸（無水） |
| 尺寸 | 10 L 到 100,000 L，或自訂長寬高。缸越大越穩定，也能容納越大的生物：箭毒蛙一隻約 38 L，龍魚需要 240 cm 長的缸，紅尾鯰需要 3,800 L 以上 |
| 陸域比例、水深 | 決定陸地面積與水量；蛙、蜥蜴、蛇、陸生昆蟲需要陸地，魚需要水 |
| 底材 | 水草泥養水草；活砂帶來海洋微生物；深厚的泥或砂（≥ 5 cm）會長出能去除硝酸鹽的脫氮菌 |
| 造景 | 岩石、沉木提供附著面與躲藏處；活石（海水）帶來大量生物，包括意外的訪客；水草吸收養分、與藻類競爭 |
| 光照 | 強光讓植物和藻類長得快，也容易藻華；珊瑚需要光，但太強會白化 |
| 過濾 | 濾材是硝化菌的家；過濾越強，水越乾淨 |
| 曝氣 | 增加溶氧 |
| 加熱器 | 維持水溫；關閉時水溫趨向室溫 22 °C |
| 水源 | 自來水：幾乎無菌，循環最慢；熟成缸水：自帶硝化菌；池塘水：多樣性最高，可能帶來掠食者；天然海水：帶來海洋浮游生物 |
| 開放系統 | 開啟後，外界生物會持續少量流入 |
| 陸域底材 | 土壤、椰土、落葉層、苔蘚、樹皮；落葉層會帶來等足類、馬陸等分解者 |
| 噴霧系統 | 維持濕度；蛙類、跳蟲、苔蘚都需要高濕度 |
| 加熱燈 | 提供曬點，爬蟲類需要曬太陽才能維持體溫 |
| UVB | 爬蟲類長期缺乏 UVB 會生病 |
| 加蓋 | 不加蓋時螞蟻、蜘蛛等可能從外面進來，果蠅會飛走 |
| 種子 | 相同種子 + 相同設定 + 相同操作 = 相同結果 |

## 5. 生物從哪裡來

| 途徑 | 例子 |
|---|---|
| 空氣與器材 | 細菌、真菌孢子、矽藻 |
| 水源 | 熟成缸水帶來硝化菌；池塘水帶來水蚤、輪蟲 |
| 水草 | 螺、渦蟲、水螅，偶爾還有蜻蜓幼蟲 |
| 活石、活砂 | 端足類、刷毛蟲、海綿、珊瑚，偶爾還有螳螂蝦 |
| 開放系統 | 浮游生物、小魚、掠食性昆蟲 |
| 土壤、落葉 | 土壤細菌、跳蟲、蟎、等足類、馬陸、蜈蚣、擬蠍 |
| 活餌逃逸 | 餵給蛙或蜥蜴的蟋蟀、果蠅沒被吃完，可能在缸裡繁殖 |
| 缸外 | 未加蓋時，螞蟻、蜘蛛、蕈蚋可能自己跑進來 |
| 你的投放 | 選擇一個類別，獲得該類別隨機生成的新物種；或從圖鑑重新投放已發現的物種 |
| 突變 | 族群繁殖時偶爾產生突變後代；若能存活繁衍，就成為新物種 |

## 5.1 物種有多少種

每個物種由一組「基因」組合而成：體型、體色、花紋、溫度偏好、鹽度偏好、食性、活動時間、防禦、繁殖方式、壽命……。理論上可能出現的物種超過 **四千億種**，每一種都有獨一無二的學名。同樣的基因組合不論在哪一缸出現，都是同一個物種。

**突變種**：族群繁殖時，偶爾會生出基因改變的後代。突變可能只是體色或花紋不同，也可能是罕見的特殊突變：白化、黑化、巨大化、侏儒化、發光、長壽、多產、廣溫、廣鹽、抗藥。突變後代若能活下來並繁衍，就成為新物種，學名會加上變種名，例如 `var. albina`（白化）。族群越大、繁殖越快，越容易出現突變種。

缸內環境會影響出現哪些物種：熱帶水溫比較容易出現「熱帶」基因的物種，高鹽度則容易出現「廣鹽」物種。

## 5.2 生老病死

所有生物都會老死。每個物種都有自己的典型壽命和最長壽命：輪蟲只活幾天，橈足類約一個多月，米蝦一到兩年，鼠魚可以活十年。

- 動物會經歷幼體、成體、老年三個階段，在物種詳情可以看到年齡結構。
- 細菌和藻類以細胞汰換的方式持續更新。
- 草履蟲這類纖毛蟲若太久沒有進行有性生殖，整個克隆會老化崩潰。
- 珊瑚、海綿是群體生物：單一水螅體會汰換，群體本身也有壽命上限。
- 蜻蜓幼蟲長大後會羽化飛走，離開水族箱。
- 蛙和蠑螈的卵、蝌蚪只能在水裡長大，變態後才上岸；沒有水域的缸無法讓牠們繁殖。
- 章魚、烏賊一生只繁殖一次，之後就會死亡。
- 龜類可以活 30–50 年以上，錦鯉、淡水白鯧甚至更久。
- 海膽、螳螂蝦、多數海水魚的幼體需要在大海漂流，所以在缸內無法繁殖，只能靠投放或搭便車進入。

## 6. 你能做的事

| 操作 | 用途 | 注意 |
|---|---|---|
| 餵食 | 供養消費者 | 過量會讓碎屑蟲、刷毛蟲爆發，並推高氨 |
| 換水 | 稀釋氨、亞硝酸、硝酸鹽 | 會帶入少量水源中的生物 |
| 調整光照 | 控制藻類、促進水草 | — |
| 調整溫度 | 改變代謝速度與適合的物種 | 超出耐受範圍的生物會死亡 |
| 曝氣 | 解決缺氧 | — |
| 投放 | 引入新生物 | 有容量限制 |
| 撈除 | 減少特定族群 | 僅限肉眼可見的生物 |
| 加入水草／活石／沉木 | 增加躲藏處與附著面 | 可能帶來搭便車的生物 |
| 殺無脊椎藥 | 清除渦蟲、水螅等 | 會殺死蝦；介形蟲有殼不受影響 |
| 殺藻劑 | 清除藻華 | 死藻會分解，造成氨上升 |
| 抗生素 | 清除藍綠菌 | 會傷害硝化菌 |
| 噴霧 | 提高濕度 | — |
| 加入落葉 | 餵養陸地分解者 | 可能帶來搭便車的生物 |
| 投放活餌 | 餵養蛙、蜥蜴 | 沒吃完的可能在缸內繁殖 |

## 7. 常見狀況

| 狀況 | 原因 | 對策 |
|---|---|---|
| 新缸白濁 | 異營細菌爆發 | 等待，通常會自行消退 |
| 棕色薄膜 | 矽藻 | 新缸正常現象；矽酸鹽耗盡後消退 |
| 綠毛藻滿缸 | 強光 + 高硝酸鹽、磷酸鹽 | 減光、換水、增加水草、投放刮食者 |
| 藍綠色黏膜 | 藍綠菌；高磷酸鹽、低水流 | 換水、增加水流、減少餵食 |
| 綠水 | 浮游微藻 | 減光；投放水蚤或雙殼貝 |
| 白色細蟲大量出現 | 碎屑蟲，餵食過量 | 減少餵食 |
| 幼蝦消失 | 渦蟲或水螅 | 撈除或用藥 |
| 魚莫名減少 | 可能有蜻蜓幼蟲或螳螂蝦 | 查看族群列表中的掠食者 |
| 珊瑚變白 | 白化：光太強或水溫太高 | 減光、降溫 |
| 生物大量死亡 | 缺氧或氨、亞硝酸過高 | 曝氣、換水 |
| 陸地長白黴 | 新造景的腐生真菌 | 等待 2–6 週；跳蟲會吃黴菌 |
| 小飛蟲很多 | 蕈蚋，土壤太濕 | 減少噴霧；投放捕食蟎 |
| 螞蟻入侵 | 未加蓋 | 加蓋 |
| 蛙類消瘦死亡 | 濕度不足或缺食 | 增加噴霧；投放跳蟲、果蠅 |
| 爬蟲類生病 | 缺 UVB 或缺曬點 | 開啟 UVB、加熱燈 |
| 某物種無法投放 | 缸太小或缺陸地／水域 | 換更大的缸或調整陸域比例 |

## 8. 圖鑑與分數

**圖鑑**收錄你發現過的每一個物種，跨缸保留，並顯示「已發現／理論總數」。

| 稀有度 | 意義 |
|---|---|
| 常見 | 基因組合很普遍 |
| 少見 | 帶有一些不常見的基因 |
| 稀有 | 多個罕見基因同時出現 |
| 傳說 | 極端罕見的基因組合 |

每個物種另有來源徽章：背景、水源、搭便車、開放系統、投放、突變。

**生態分數**由三項組成：
- 多樣性：物種多，且數量分布均勻
- 營養層深度：食物鏈越長越高
- 穩定度：近 30 遊戲日總生物量波動越小越高

## 9. 離線

關閉遊戲後再開啟，會自動補算離開期間的變化，最多 30 遊戲日（約 30 分鐘現實時間），並顯示離開期間的摘要。

## 10. 存檔

- 自動存檔：每 30 秒、切換分頁時、重大事件後；族群與水質歷史每個遊戲日記錄一次。
- 所有資料存於瀏覽器本機的資料庫；清除瀏覽器資料會刪除存檔。
- 設定頁可匯出整個資料庫（`.sqlite3` 檔）備份，或匯入還原。
- 同一時間只能在一個分頁開啟遊戲。
- 「重置」會開新缸，圖鑑保留。
